# Trained model artifacts
The original trained model bundles are installed in `models/`, and the fine-tuned Whisper seed-0 checkpoint is installed in `data/`.
Keep these filenames unchanged. The fine-tuned models require `finetune_whisper.py`, `whisper_ft_embedder.py`, and `splits.py`.
The Whisper base model may be downloaded from Hugging Face on first inference if it is not already cached.
